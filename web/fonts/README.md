# Fonts

These fonts are served by joyshare itself, so no visitor's browser contacts an outside font service.
All are open source under the SIL Open Font License 1.1 and were taken from the Fontsource project
(https://fontsource.org), Latin subset.

| File | Font | Used for |
|---|---|---|
| `unbounded.woff2` | Unbounded | Display lettering (default) |
| `syne.woff2` | Syne | Display lettering option |
| `tilt-warp.woff2` | Tilt Warp | Display lettering option |
| `rubik-glitch.woff2` | Rubik Glitch | Display lettering option |
| `rubik-mono-one.woff2` | Rubik Mono One | Display lettering option (Zine look) |
| `fredoka.woff2` | Fredoka | Display lettering option and body text (Clay look) |
| `special-elite.woff2` | Special Elite | Body text (Zine look) |
| `bangers.woff2` | Bangers | Display lettering option (Comic look) |
| `comic-neue.woff2` | Comic Neue Bold | Body text (Comic look) |
| `audiowide.woff2` | Audiowide | Display lettering option (Vaporwave look) |
| `monoton.woff2` | Monoton | The name at the top (Vaporwave look) |
| `space-grotesk.woff2` | Space Grotesk | Body text |

The Windows 95 look uses the fonts already on the device (Tahoma and similar), so it ships no font file.
